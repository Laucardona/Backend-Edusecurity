# Backend EduSecurity

Proyecto backend desarrollado con Spring Boot para la plataforma EduSecurity.

## Tecnologías utilizadas

- Java 21
- Spring Boot
- Maven
- Spring Data JPA
- Arquitectura por capas
- DTO (Data Transfer Object)

## Estructura del proyecto

```text
src/main/java/edusecurity
├── controller
├── dto
├── entity
├── repository
└── service
```

## Módulos implementados

- Gestión de lecciones
- Gestión de módulos
- Gestión del progreso de los estudiantes

## Ejecución del proyecto

Instalar dependencias:


mvn clean install


Ejecutar la aplicación:


mvn spring-boot:run
